# Aulia Cosmetics Website

Website e-commerce untuk toko kosmetik Aulia Cosmetics dengan semua fitur yang diperlukan untuk penjualan online.

## Fitur Utama

1. **Halaman Utama** dengan daftar produk
2. **Fitur Pencarian** berdasarkan kategori, harga, dan kata kunci
3. **Halaman Produk** dengan detail lengkap
4. **Keranjang Belanja** dengan kemampuan update
5. **Sistem Checkout** dan pembayaran
6. **Desain Responsif** untuk desktop dan mobile
7. **Gambar Produk** yang menarik dari Unsplash

## Struktur Website

- **index.html** - Halaman utama
- **style.css** - Styling utama
- **script.js** - JavaScript untuk halaman utama
- **cart.html** - Halaman keranjang belanja
- **cart.js** - JavaScript untuk keranjang
- **checkout.html** - Halaman checkout
- **checkout.js** - JavaScript untuk checkout
- **README.md** - Dokumentasi ini

## Cara Hosting di GitHub Pages

1. Buat akun GitHub jika belum punya
2. Buat repository baru dengan nama "aulia-cosmetics"
3. Upload semua file ke repository
4. Pergi ke Settings > Pages
5. Pada bagian "Source", pilih "main" branch
6. Klik Save
7. Tunggu beberapa menit, website akan live di: `https://username.github.io/aulia-cosmetics`

## Cara Menggunakan di Local

1. Download semua file
2. Buka file `index.html` di browser
3. Pastikan koneksi internet aktif untuk memuat gambar dari Unsplash

## Pengujian Fitur

Setelah dihosting, uji fitur berikut:

1. **Pencarian produk** - Coba cari "matte" atau "glow"
2. **Filter kategori** - Pilih kategori tertentu
3. **Filter harga** - Coba filter berdasarkan rentang harga
4. **Keranjang belanja** - Tambah produk ke keranjang
5. **Checkout** - Coba proses checkout lengkap
6. **Responsif** - Buka di mobile dan desktop
7. **Gambar** - Pastikan semua gambar produk muncul
